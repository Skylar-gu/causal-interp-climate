# `graphcast_sae.appendix` — the negative appendices

| appendix | scripts | environment |
|---|---|---|
| `app:parity` Nyquist parity family (Tables `tab:parity-census`, `tab:parity-refit`) | `parity_scan.py` (semidiurnal parity index over the dictionary, from `results/fs_cgv2_actseries.npy`, regenerated by `concepts/cgv2_actseries.py`, not shipped), `identify_edge_features.py` (what f3357 / f3319 / f3004 are: fields, rotation, intervention) | CPU; the latter streams ERA5 |
| `app:topk` sparsity-budget competition (Table `tab:p0`) | `p0_transmission_probe.py` (`run` on GPU, then `analyze`), `mediation_select.py` → `mediation_run.py` (GPU clamp battery) → `mediation_analyze.py`, `mediation_topk_margin.py` (rank-k margin on real activations) | GPU for the rollouts |
| `app:mesh` no locality / receptive field (Tables `tab:hops`, `tab:census`) | `mesh_speed_limit.py` (pure geometry from the checkpoint header), `footprint_census.py` (size vs spread), `geom_midrollout.py` (PC alignment mid-rollout) | CPU |
| `app:taxonomy` bars that cannot fail — the skill-decomposition lane (GraphCast vs IFS-HRES) | `skill_sanity_gate.py` → `skill_extract.py` (GPU) → `skill_decompose.py` / `skill_decompose_atlead.py` → `skill_ablate.py` (GPU) → `skill_figure.py` | mixed |

None of these writes a file that ships in `results/`; each docstring's `Inputs:` line names
what it reads and `docs/REPRODUCE.md` says how to regenerate it. `tests/mediation_selftest.py`
is the CPU exactness test the mediation clamp must pass before any GPU time is spent.
